Použití výsledků

MicroAxis poskytuje výpočty a údaje jako pomůcku pro technickou praxi. Výsledky jsou orientační; za volbu řezných podmínek, nástrojů, upínání a za kontrolu výsledků odpovídá uživatel.

PathCheck

PathCheck je simulace podle NC programu a zadaných nástrojů. Nenahrazuje kontrolu programu na stroji, zkušební běh ani kontrolu kinematiky a upnutí. Program, který PathCheck neoznačí, nemusí být bez chyb.

Autor neodpovídá za škody na strojích, nástrojích, obrobcích ani za zmetky vzniklé použitím aplikace.

Údaje výrobců

Údaje výrobců (katalogy nástrojů, povlaky, řezné podmínky) pocházejí z veřejných podkladů těchto firem; ochranné známky patří jejich vlastníkům a autor s nimi nemá smluvní vztah.

Use of results

MicroAxis provides calculations and data as an aid for engineering practice. Results are indicative; the user is responsible for choosing cutting data, tools and workholding and for checking results.

PathCheck

PathCheck is a simulation based on the NC program and the tools entered. It does not replace checking the program on the machine, a dry run or checking kinematics and fixturing. A program that PathCheck does not flag is not guaranteed to be error-free.

The developer is not liable for damage to machines, tools or workpieces or for scrapped parts resulting from use of the app.
